# Gizlilik — Messy Janitor

Kişisel veri toplanmaz. Hesap, e-posta, reklam kimliği yok.

## Yerel kayıt

Oyun ilerlemesi Windows'ta Godot userdata altında:

`%APPDATA%\Godot\app_userdata\Messy Janitor\`

Dosyalar: seviye, can, cüzdan, rozet, ayar, skor, curse (`*.cfg`). Cihazın dışına çıkmaz — Steam Cloud açılana kadar.

## Steam Cloud (App ID + GodotSteam sonrası)

Açık olursa yalnızca yukarıdaki cfg'ler Remote Storage'a yazılır. Kişisel profil yok.

## Steam overlay / başarılar

Steam istemcisi kendi hesabını kullanır. Biz Steam'den isim veya e-posta çekmeyiz.

## İletişim

Steam partner kaydındaki yasal unvan. Store sayfasındaki destek e-postası (panelde doldurulur).

---

# Privacy — Messy Janitor

No personal data is collected. No accounts, email, or advertising IDs.

Progress lives in local Godot userdata (`*.cfg` only). If Steam Cloud is enabled later, those same files sync — nothing else.
